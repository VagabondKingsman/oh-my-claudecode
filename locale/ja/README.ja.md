# oh-my-claudecode — 日本語オーバーレイ

> このオーバーレイは `OMC_LOCALE=ja` のときに有効になります。
> 正本（canonical）は英語版 `README.md` のままです。日本語固有のチェックリストとペルソナのみ追加します。

## このオーバーレイが提供するもの

- vibecodekit-hybrid パイプラインの **日本語ペルソナ・バンク**（顧客・モデル・ユーザー・運用者）
- 日本語プロダクトに頻出する **12 のアンチパターン・チェック**（敬語混在、半角カナ事故、JIS X 0208 範囲外、和暦／西暦混在、〒住所欠落、契約書 PDF の文字化け、絵文字レンダリング差異、SHA 経由の人名安定性、苗字／名前の入れ違い、姓名分離 CSV 化け、IME 変換確定タイミング、ユニコード正規化境界）
- **Phase 4d (RRI-SEC)** で `OMC_LOCALE=ja` のときに必須となる **APPI（個人情報保護法）控制行**
- vibecodekit-hybrid の SKILL 群が `OMC_LOCALE=ja` を検出したときの動作概要

## 有効化方法

```bash
# シェルセッションで一回だけ有効化
export OMC_LOCALE=ja

# プロジェクト全体で固定
echo '{"locale":"ja"}' > .omc/locale.json

# CLI フラグで一回だけ
omc vibecodekit scaffold demo --locale ja
```

ロケール解決は `.omc/locale.json` → `OMC_LOCALE` → 既定値 (`en`) の順で評価されます。

## 12 のアンチパターン・チェック（日本語プロダクト向け）

`vibecodekit-hybrid-rri-ux` および `vibecodekit-hybrid-rri-t` は `OMC_LOCALE=ja` を検出すると、以下を必須レビュー軸として追加します:

1. **敬語の混在** — 「です・ます」「だ・である」「タメ口」がページ内で揺れていないか。
2. **半角カナ事故** — エクスポート CSV、PDF 取り出し、メール送信などで `ｶﾅ` が混入していないか。
3. **JIS X 0208 範囲外の文字** — 旧字体・異体字（髙・﨑・𠮷など）がデータベース／フォントで欠落していないか。
4. **和暦／西暦の混在** — 同一画面で「令和7年」「2025年」が混ざる UI を避ける、または明示的にラベルする。
5. **〒住所欠落** — 郵便番号→住所自動入力のフォールバック、住所2行目（建物名）の有無。
6. **契約書 PDF 文字化け** — `pdftotext` 通過後に `□` や `?` が出ない（RRI-T のフィクスチャと連動）。
7. **絵文字レンダリング差異** — Apple／Google／Twemoji で意味が変わる絵文字を本文に使っていないか。
8. **SHA 経由の人名安定性** — `田中` と `田中　` の SHA が異なるバグ（trailing 全角スペース／IDN）。
9. **苗字／名前の入れ違い** — `firstName` / `lastName` の並びをローカライゼーション方針と一致させる。
10. **姓名分離 CSV 化け** — エクスポート時に `氏名` を分離した結果、外字が `?` に化けないか。
11. **IME 変換確定タイミング** — `compositionend` 前に検索 API を叩いて再変換が壊れる UX バグの検出。
12. **ユニコード正規化境界** — NFC ↔ NFD で `が` が gapped→garbled になるケース（特に macOS 由来 CSV）。

これら 12 項目は **MISSING** 軸として `rri-ux-critic` および `rri-tester` に渡されます。一つでも MISSING があれば release gate は最低でも 🟡 になります。

## Phase 4d (RRI-SEC) — APPI 控制行

`OMC_LOCALE=ja` 検出時、`rri-security-auditor` は **APPI（個人情報の保護に関する法律）** 行を Compliance Evidence セクションに必須として追加します:

- **APPI 第 17 条**（適正取得）— 取得時の利用目的の通知・公表証跡
- **APPI 第 21 条**（漏えい等の報告）— 個人情報保護委員会への 3〜5 日以内報告フロー
- **APPI 第 28 条**（越境移転）— 第三国への移転がある場合、本人同意ログ／移転先の安全管理措置
- **マイナンバー法**（該当する場合）— マイナンバーは「特定個人情報」として隔離保管され、SQL や API レスポンスに混入しない

詳細は `locale/ja/agents/rri-security-auditor.ja.md` を参照してください。
